# STM32 Custom Development Board

A custom STM32F103 development board designed in KiCad with USB connectivity, onboard power regulation, GPIO expansion, and SWD programming support.

---

## Overview

This project focuses on designing a custom STM32-based PCB while learning practical embedded hardware design concepts and PCB development workflow.

The board includes:

* STM32F103C8x6 microcontroller
* Micro USB interface
* AMS1117 3.3V regulator
* Crystal oscillator
* Decoupling capacitor network
* SWD programming interface
* GPIO expansion headers
* Mounting holes

---

## Features

* Custom STM32F103 PCB design
* USB power and communication support
* Onboard 3.3V voltage regulation
* SWD debugging/programming header
* External crystal support
* GPIO breakout headers
* Designed in KiCad
